Minecraftia is a Minecraft-style pixel font drawn by Andrew Tyler. It is not
Mojang's font and contains no Mojang assets. Materione uses it only to show
player-visible text in the editor the way the game draws it (docs/architecture/web.md,
"Rich text"). ShareAlike applies to the font itself: an adapted version of the
font must stay under CC BY-SA 3.0. It does not extend to the editor's code.
