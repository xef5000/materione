make one mega Minecraft plugin that allow server owners to build their entire server, in much less time.

Current solutions take time because:
- They all target one problem
- They all function with commands or YAML formats, with each their own documented syntax.

To be efficient, admins need to learn the syntax for dozens of plugins. Then, they have to pair them with other plugins to make them work.

This is where Materione (this plugin) comes into play. It combines the functionality of every major content-creation plugin, and ships a web-ui with it. There, admins will be able to create everything and intertwine every feature with each other.

End goal: combining the following plugins into one:
- ItemsAdder (https://itemsadder.com/)
- Nexo (https://nexomc.com/)
- Oraxen (https://oraxen.com/)
- BetterHUD (https://modrinth.com/plugin/betterhud2)
- https://mythiccraft.io/index.php?resources/%E2%AD%90mythichud%E2%AD%90custom-bars-and-number-displays%E2%9C%85replace-vanilla-look%E2%9C%85auto-resource-pack-builder.394/
- https://www.spigotmc.org/resources/deluxemenus.11734/

And, on top of that, ship a web-ui that integrates blockbench (which is open source) directly into the browser: easy to create assets for the plugin.

To do this, we need to look at how these plugins are made, and utilize a lot of libraries. It's unrealistic to assume that everything can be remade from scratch.

Useful libraries:
- ProtectionLib (https://github.com/oraxen/protectionlib)
- Oraxen (it is open-source, useful to look at as a reference) (https://github.com/oraxen/oraxen)
- creative (resourcepack generated by plugin) (https://github.com/unnamed/creative)
- FoliaLib (https://github.com/TechnicallyCoded/FoliaLib)
- Actions (to save actions in yaml) (https://github.com/iGabyTM/Util-Actions)
- triumph gui (to create custom GUIs) (https://github.com/TriumphTeam/triumph-gui)
- custom block data (store block data in chunks, not DB) (https://github.com/mfnalex/CustomBlockData)
- more persistent data types (https://github.com/mfnalex/MorePersistentDataTypes)
