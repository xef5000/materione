# Contributing to Materione

Thanks for your interest in contributing to Materione!

## Ways to contribute

- Open an issue to report bugs or request features.
- Open a pull request with fixes or improvements.

## Pull request guidelines

1. Keep changes focused and clearly scoped.
2. Include or update tests when relevant.
3. Update documentation when behavior changes.
4. Ensure your changes are compatible with the project's Apache-2.0 licensing.

## Contributor agreement (CLA)

By opening a pull request, you confirm that you have read and agree to the terms in [`CLA.md`](./CLA.md).

By submitting a contribution, you also agree that your contribution is provided under the Apache License 2.0 terms used by this repository.

## Conduct

Be respectful and constructive in all project interactions.
